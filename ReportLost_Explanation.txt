          → e.target = the specific input the user typed in.

Line 34–37:
  setFormData((prev) => ({

    [name]: type === "checkbox" ? checked : value,
  }));
  → We update only the field that changed, keeping all other values the same (...prev).
  → [name] uses the field's name dynamically (e.g. if name="itemName", it updates formData.itemName).
  → If it's a checkbox, we use checked (true/false). Otherwise, we use the typed value.

  KEY POINT: One handleChange function handles ALL inputs. That's why every input has
             name="something" and onChange={handleChange}.

===========================================================
  KEY REACT CONCEPTS USED IN THIS FILE — QUICK SUMMARY
===========================================================

useState       → Store data that can change. React re-renders when it changes.
useEffect      → Run code when the component loads (like "on page open").
handleChange   → One function for ALL inputs using the input's `name` attribute.
formData       → One object holding all form field values at once.
Controlled Input → value={...} + onChange={...} = React controls the field's value.
Conditional Rendering → {condition && <Component />} = show only if condition is true.
navigate()     → Redirect user to another page programmatically.
localStorage   → Browser storage. Survives page refresh. Used to save/load reports.
JSON.stringify → Convert JS object to text (for storage).
JSON.parse     → Convert text back to JS object (for reading).
...spread      → Copy all fields from an object: {...prev, key: newValue}.
